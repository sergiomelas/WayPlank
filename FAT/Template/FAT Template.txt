   [  ] 3.1 None: Dock permanently visible, never hides
   [  ] 3.2 Autohide: Hidden by default, reveals when cursor touches screen edge
   [  ] 3.3 Intellihide (Intelligent): Window overlaps dock -> hides; moves away -> reveals

   [  ] 3.4 Dodge Active: Hides only if focused active window overlaps dock
   [  ] 3.5 Dodge Maximized: Hides only when a window is maximized
   [  ] 3.6 Window Dodge: Hides if any window (active or inactive) overlaps dock
   [  ] 3.7 Pressure / Hover Reveal: Mouse touching edge unhides dock immediately

   [  ] 4.3 Sticky Windows: Window set on all workspaces -> dock dodges on every workspace
   [  ] 4.4 Dynamic Workspaces: Adding or removing dynamic workspaces on the fly -> handled without stale lookups or crashes

   [  ] 6.4 External Trash Sync: Empty/fill trash from external file manager (Dolphin/Nautilus) -> icon updates state via D-Bus
   [  ] 6.5 Screenshot Docklet: Click triggers rectangular selection; context menu triggers area/full/window/folder
