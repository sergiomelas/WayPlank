        Bug: (KWin) When display scaling or DPI changed in KDE Plasma, the
        logical resolutions and coordinates of connected displays changed (e.g.
        1920x1080 -> 1536x864). PositionManager.get_monitor_for_plug_name()

        P2219H (1) [1920x1080 @ 0,0]"), failing exact and coordinate matching,

        matching (comparing model and instance count independent of volatile
        geometry brackets) and dynamically refreshed prefs.Monitor with current
        geometry. In DockWindow.vala, eliminated destructive hide() calls and
        guarded GtkLayerShell.set_monitor() to only trigger when target monitor
        changes, ensuring the dock surface remains anchored to its assigned
        display across DPI and fractional scaling transitions.

        dock via 'wayplank --replace' -> cleanly
        takes over without zombie scripts: wayplank --replace => Unknown option
        --replace.
        Bug: (Cross-Compositor) The CLI option parser in AbstractMain.vala
        registered {"reload", 'r'} in the GOptionEntry array, allowing 'wayplank
        -r' and 'wayplank --reload' to parse correctly, but omitted {"replace",
        0}. When invoked with '--replace', GLib.Application rejected the
        argument with 'Unknown option --replace'.
        Solution: Added {"replace", 0, 0, OptionArg.NONE, null, "Restart and
        replace running dock instance", null} to the options table in
        AbstractMain.vala. Now both 'wayplank -r' and 'wayplank --replace'
        cleanly terminate any running instance and start a fresh dock lifecycle
        without leaving zombie scripts or orphaned processes.
   [ko->ok] 9.6 (KWin) Rapid Display Reconfiguration / DPI Storm: Repeated rapid
        scaling/DPI modifications in KDE
        System Settings -> zero compositor lockups or synchronous D-Bus stalls:
        Freeze occurred during rapid multi-DPI slider adjustments in KDE.
        Bug: (KWin) In KWinBridge.vala, workspace.windowRemoved was connected to
        sendWindowStateEx(w) directly, bypassing the 50ms QTimer debouncer and
        issuing synchronous D-Bus calls on KWin's main thread. During rapid
        DPI/scaling changes, layer surface teardown triggered repeated
        unthrottled IPC calls while KWin was reconfiguring DRM outputs. In
        addition, DockWindow's update_layer_shell_monitor() unconditionally
        unmapped the dock via hide(), provoking unnecessary surface destroy
        cycles.
        Solution: Routed workspace.windowRemoved through scheduleWindowState()
        and eliminated destructive hide() calls in DockWindow.vala. 100% of KWin
        window lifecycle events are now debounced through the single-shot
        QTimer, D-Bus calls have bounded timeouts (2000ms), and PositionManager
        has re-entrancy protection, guaranteeing zero event storms or compositor
        stalls.
   [ok] 9.7 (Cross-Compositor) Window Title & State Flood Debounce: Rapid burst
        of window title changes or
       fast open/close cycle -> absorbed by 50ms debouncer without CPU spikes,

LABWC BUGS / NOTES:
- 4.1 (Labwc) Virtual Desktops & Workspaces: zwlr_foreign_toplevel_management_unstable_v1
  lacks spatial window coordinates; workspace dodging operates via Dodge Active mode.
- 6.5 (Labwc) Screenshot Docklet: Requires 'grim' and 'slurp' on wlroots; added
  Recommends in Debian package control so they are automatically installed.
- 7.1 (Labwc) Preferences Dialog Centering: Solved by configuring Labwc windowRule
  with AutoPlace policy="center" in rc.xml.
- 2.7 (Labwc) Attention / Urgent State: Architectural note - The
  zwlr_foreign_toplevel_management_unstable_v1 protocol specification only
  defines MAXIMIZED, MINIMIZED, ACTIVATED, and FULLSCREEN states. It lacks an
  urgency/attention notification event; hence native wlroots windows do not emit
  protocol-level attention signals.
- 2.13 (Labwc) Non-ASCII / UTF-8 Window Titles: In wlr-toplevel-bridge.c,
  g_strescape() previously escaped UTF-8 bytes (>127) as octals (\303\250),
  producing invalid JSON that caused Json.Parser in LabwcBackend.vala to fail
  and clear all running indicators. Fixed with a dedicated RFC 8259 JSON
  escaper.
- 9.7 (Labwc) Window Title & State Flood Debounce: In LabwcBackend.vala, Wayland
  toplevel callbacks previously triggered immediate synchronous JSON generation
  and parsing on every event. Added a 50ms single-shot GLib.Timeout debouncer to
  throttle event bursts.
