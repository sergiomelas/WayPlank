PLASMA BUGS / NOTES:
- Desktop Launcher / Process Lifecycle:
  * When launching Wayplank directly via double-click on data/wayplank.desktop from Dolphin/KIO, KDE requires the file executable flag (chmod +x) for local desktop entries outside /usr/share/applications/ (preventing "kf.config.core: Access denied, not owned by root and executable flag not set").
  * When Wayplank is already running in background (e.g. systemd autostart app-wayplank@autostart.service), starting another instance without --replace yields "Wayplank is already running. Refreshing dock surface and position." without killing the previous process; to restart and cleanly take over, use wayplank --replace & or right-click the launcher -> "Restart Dock".
  * Fixed data/wayplank.desktop with chmod +x, cleaned deprecated keys, added Desktop Action Restart, and updated BuildDeb.sh to package it directly along with /usr/share/applications/plank.desktop symlink.
