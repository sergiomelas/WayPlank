# Wayplank V0.4.2 Detailed Changelog

Release Date: 2026-09-28

This document contains the comprehensive, itemized technical changelog for the massive **V0.4.2** release milestone of Wayplank.

---

## Detailed Changes & Technical Enhancements

- **Purged AI Prototyping Hallucination (Thanks to Reddit feedback)**: Removed an empty placebo conditional check (`win != null && !win.has_native ()`) and its misleading comments in `DockWindow.vala` (`enter_notify_event`) that were spotted by a user on Reddit, along with leftover minor stubs.
- **Monolithic Embedded Wayplank Logo in About Dialog**: Bundled the high-resolution vector Wayplank logo directly into the compiled GResource binary (`/net/launchpad/plank/img/wayplank.svg`), rendering the official crisp Wayplank branding in the About dialog independently of system icon themes while keeping desktop launchers using `plank` for seamless cross-distribution theme compatibility.
- **Native Drag & Drop Shortcuts and Files into Dock Folders (`FileDockItem`)**: When dropping `.desktop` shortcuts, files, or folders directly onto a pinned folder icon on the dock, WayPlank now natively accepts them, copies the dropped items into the target directory (with full recursive directory support), automatically applies executable permissions (`0755`) to `.desktop` files for instant launchability, invalidates the folder's Cairo stack icon buffer to immediately refresh the stack preview thumbnail, and triggers an engaging bounce animation (`AnimationType.BOUNCE`). External drops over folder items are cleanly routed in `DragManager.vala` without triggering dock launcher unpinning or repositioning, and `DockRenderer.vala` keeps folder targets bright and highlighted while dragging over them.
- **Dynamic Transient Dock Items Synchronization**: Connected `WindowManager.windows_refreshed` directly to `sync_compositor_windows()` in `ApplicationDockItemProvider.vala`. Unpinned running applications now dynamically appear on the dock with temporary icons the exact instant their first window opens, and cleanly vanish the moment their last window closes, providing seamless, real-time lifecycle tracking without requiring manual mouse hover or dock reload.
- **Real-Time Indicator Dots & FrameClock Wakeup (0ms Latency)**: Fixed running application indicator dots (glowing dots under icons) failing to update immediately upon window open, focus, or close events. Unconditionally hooked `GdkFrameClock.begin_updating()` in `Renderer.vala` and filtered out `client.deleted` windows in the KWin bridge, ensuring instantaneous, 0ms latency indicator redraws synchronized directly with Wayland compositor frame callbacks (`wl_surface.frame`).
- **Visual Pinning Boundary & Dynamic Dock Organization**: The visual separator (`SeparatorDockItem`) now acts as a strict organizational boundary between pinned launchers (left/top) and dynamically created transient running applications (right/bottom). Dragging an item across the separator dynamically promotes or demotes its pinning state, while internal icon reordering strictly respects and preserves the separator's integrity.
- **Robust Command Line Parsing in Desktop Matcher (`GLib.Shell.parse_argv`)**: Replaced basic whitespace splitting on `Exec=` lines in `Matcher.vala` with `GLib.Shell.parse_argv` (and robust fallback). This guarantees reliable matching for applications with quoted paths or embedded spaces (e.g. `/opt/My App/binary`), eliminating false-negative running states for complex third-party software.
- **Layer-Shell Margin Clamping & UI Glitch Prevention**: Clamped calculated tooltip and hover window margins in `HoverWindow.vala` against negative coordinates and eliminated redundant layout passes, preventing GTK Layer Shell protocol errors when tooltips appear near screen edges.
- **CLI Options Standardization & Short Flag Restoration (`-p`, `-v`, `-V`)**: Restored the missing short flag `-p` for `--preferences` in `AbstractMain.vala` (which historically had a null byte `0` in upstream Plank, causing `Unknown option -p`). Swapped and aligned short flags to modern Linux standards: `-v` for `--version` and `-V` for `--verbose`, fully synchronized across GLib option entries, early CLI intercepts, and terminal `--help` output.
- **Launch standard [Desktop Action …] entries through GDesktopAppInfo**: `launch_action()` instead of treating their Exec lines as generic commands. Legacy Unity quicklists (X-Ayatana-Desktop-Shortcuts) still use the existing launch path.
- **Fixed running detection and window matching for custom and specialized launchers (e.g. virtual machines, web apps, dedicated profiles)**: Process scanning is now isolated to the user's UID to prevent system daemons from triggering false-positive running states, while window titles and command-line arguments are now matched to ensure custom shortcuts correctly launch and toggle their windows.
- **Comprehensive Code Audit & Bug Hunt Resolution**: Eliminated phantom KWin script leaks on dock reloads, added non-blocking D-Bus timeout safeguards against GUI freezes, fixed monitor switching between identical-resolution displays, clamped layer-shell tooltip margins against negative coordinate errors, included `~/.local/share` in user app scans, resolved duplicate pinned launcher icons, and cleanly disconnected all lifecycle signals to eliminate memory leaks and crashes.
- **Smart Sleep & Resume Auto-Recovery**: Implemented proactive power-management and screen-lock listeners subscribing to systemd-logind `PrepareForSleep` and ScreenSaver `ActiveChanged` signals. Wayplank now automatically survives system suspension and hibernation by reloading KWin bridge scripts, re-binding layer-shell surfaces to awakened outputs, and unhiding the dock upon system resume. In addition, launching `wayplank` while an instance is already running (or executing `wayplank --reload`) now signals the primary instance to immediately wake up, refresh its surfaces, and reposition cleanly on screen.
- **Modern Multi-Tab Shortcuts Guide, Clean CLI & UI Enhancements**: Redesigned the local help guide into a modern multi-page `Gtk.Stack` dialog with category tabs (*Mouse Actions*, *Drag & Drop*, *Shortcuts & Tools*) and a centered OK button matching the Preferences window layout. Sanitized the CLI by purging obsolete X11 options (`--display=DISPLAY`), adding terminal cheatsheets (`--shortcuts`), early parameter intercepts, and a direct "Report a Bug Online..." menu link. Restructured the developer menu into a clean native GTK submenu.
- **Standalone Builder Pipeline & Compiler Bug Fixes**: Modernized `BuildDeb.sh` and `BuilsBin.sh` with clean, emoji-based terminal output (purging legacy ASCII hash borders). Fixed build-pipeline failure masking by enforcing strict exit-code validation on `valac` and `dpkg-deb`, purging stale binaries prior to compilation, and adding terminal pause prompts so compilation failures halt immediately without generating corrupted packages or falsely reporting build success.
- **Native Wayland Smooth Scroll & Multi-Window Cycling**: Implemented smooth mouse wheel event translation (`Gdk.ScrollDirection.SMOOTH` deltas) on Wayland, mapping vertical wheel deltas into UP/DOWN cycles with rate-limiting accumulators. In `WindowManager.vala` and `ApplicationDockItem.vala`, added deterministic window cycling: rolling the wheel over an application with multiple open windows now smoothly and reliably cycles focus forward and backward across all its windows.
- **Smoke Poof Animation**: Resolved the issue where the unpinning smoke puff (`PoofWindow`) always triggered over the dock icon. `DragManager` now queries the real pointer release coordinates via GDK root coordinates, device seats, and layer-shell monitor offsets with directional fallbacks, guaranteeing the smoke poof animation renders precisely where the user releases the dragged icon outside the dock.
- **Instantaneous App Pinning from .desktop file**: Fixed latency and drop rejection when dragging `.desktop` files from Dolphin onto the dock. Proactively pre-fetches drag data during `drag_motion`, correctly falls back to `default_provider` when hovering over items, recognizes running `TransientDockItem` instances and promotes them to pinned items without delay, and triggers immediate animated redraws upon drop for zero-latency, glitch-free pinning.
- **Declaration of Independence from X11 & Native Hardware Modernization**: WayPlank has officially severed all ties with legacy X11: purged all remaining X11, XRandR, XInput, and libwnck dependencies, obsolete vapi bindings, and build flags. The codebase now compiles with **0 warnings and 0 errors**. Eliminated the final compiler deprecations by reimplementing multi-monitor discovery via native `Gdk.Monitor` hardware querying, featuring automatic disambiguation for identical display models (e.g., `DELL U2720Q (1)`, `DELL U2720Q (2)`). Additionally, replaced continuous 2-second background disk/proc polling with event-driven `inotify` directory monitors and on-demand matching, achieving zero idle CPU/disk I/O and perfectly fluid icon zoom animations.
- **Integrated In-App Wayland Migration & Architecture Report**: Embedded the comprehensive technical migration documentation (`Documentation/wayplank_x11_to_wayland_report_en.md`) directly into the compiled monolithic binary as a compressed GResource (`/net/launchpad/plank/doc/report.md`). Added a new context menu entry ("Wayland Migration Report...") in the Preferences & About section of the dock context menu. When invoked, it dynamically exports an optimized HTML report styled with GitHub Markdown CSS and Mermaid.js, rendering all architecture flowcharts, sequence diagrams, and markdown tables natively in the user's default browser with full offline fallback support and zero external package dependencies.
